# 防短视频1.0

一个只做一件事的安卓小工具：**检测到你打开抖音，就弹窗提醒，并自动把你退回桌面。**

当前版本 **1.0**，只监控抖音。后续会更新适配更多短视频软件（快手、小红书、B站、YouTube、TikTok 等）。目前仅支持安卓手机。

## 功能

- 前台应用是抖音时，立刻弹出提醒「你又在刷抖音了！」
- 只有「退出抖音」一个选项，2.2 秒不操作也会自动退回桌面
- 想继续刷，只能主动去系统设置里关闭本应用的无障碍服务
- 首页可以看今天被叫停的次数

## 安装

1. 下载 [Releases](../../releases) 里的 APK，传到手机安装
2. 允许「安装未知应用」
3. 安卓 13 及以上：设置 → 应用 → NoScroll → 右上角「⋮」→「允许受限设置」
4. 打开 NoScroll → 点「打开无障碍设置」→ 找到 NoScroll 并开启
5. 打开抖音测试：应立即弹出提醒并退回桌面

部分国产系统（小米、OPPO、vivo 等）可能需要额外允许「显示在其他应用上层」「后台弹出界面」，否则提醒无法显示。

## 隐私

- 不申请网络权限，数据不会离开手机
- 只读取当前前台应用的包名，不读取屏幕内容、不读取聊天记录
- 所有统计数据只保存在本机

## 从源码构建

```bash
./gradlew assembleRelease
```

需要 JDK 17+ 和 Android SDK 34。正式签名所需的 `keystore.properties` 与 `signing/` 目录不会提交到仓库。
